# Programa Anual de Trabajo DATMP 2027 · eBook

Versión 1.2 · 21 de octubre de 2026
División de Apoyo Técnico y Mejora de Procesos · Coordinación de Bienestar Social · IMSS

Versión en formato de libro electrónico (32 páginas tamaño carta).

## Navegación

- Las hojas pasan con efecto de libro real (giro 3D sobre el lomo, sombras y curvatura).
- Clic en la mitad derecha o izquierda del libro, flechas en pantalla, teclas ← → / Re Pág / Av Pág, o deslizar el dedo en el celular.
- Barra inferior para saltar a cualquier página.
- Botón «Índice» con la lista de páginas.
- En pantallas amplias se muestran dos páginas a la vez; el Mapa estratégico (horizontal) se extiende sobre la doble página.
- Enlace directo a una página: `index.html#p20`.
- Botón «PDF» para imprimir o guardar el documento completo en tamaño carta.

## Contenido

- `index.html`: el eBook.
- `assets/`: logotipo institucional y fotografía.

## Publicación en GitHub Pages

1. Sube el contenido de esta carpeta a la raíz de un repositorio (o a una carpeta `docs/`).
2. En **Settings → Pages**, elige la rama `main` y la carpeta correspondiente.
3. El eBook queda disponible en `https://<usuario>.github.io/<repositorio>/`.

Las tipografías (Manrope, IBM Plex Mono y Noto Sans) se cargan desde Google Fonts.
